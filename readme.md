================================================================
  QUIZ APP — ВИКТОРИНА ПО ОСНОВАМ FRONTEND
================================================================

Веб-викторина на Flask с сохранением прогресса в серверной сессии.
Пользователь отвечает на 5 вопросов по HTML, CSS и JavaScript,
а результат сохраняется между запросами благодаря Flask session.

----------------------------------------------------------------
  ВОЗМОЖНОСТИ
----------------------------------------------------------------

  • 5 вопросов по основам HTML, CSS и JS
  • Сохранение прогресса на сервере через Flask session
  • Защита от повторных ответов на один вопрос
  • Мгновенная подсветка правильного/неправильного ответа
  • Кнопка "Пройти снова" — полный сброс прогресса
  • Адаптивный дизайн с градиентным фоном
  • REST API для взаимодействия клиента и сервера

----------------------------------------------------------------
  ТЕХНОЛОГИИ
----------------------------------------------------------------

  Backend:
    - Python 3.8+
    - Flask

  Frontend:
    - HTML5
    - CSS3 (Flexbox, градиенты, transition)
    - Vanilla JavaScript (Fetch API, async/await)

  УСТАНОВКА И ЗАПУСК

  1. Клонируй репозиторий:

       cd quiz-app

  Приложение будет доступно по адресу:
       http://localhost:5001

----------------------------------------------------------------
  API
----------------------------------------------------------------

  Все ответы возвращаются в формате JSON с текущим состоянием.

  +--------+----------------+----------------------------------+
  | Метод  | Эндпоинт       | Описание                         |
  +--------+----------------+----------------------------------+
  | POST   | /api/answer    | Проверить ответ, обновить счёт   |
  | POST   | /api/next      | Перейти к следующему вопросу     |
  | POST   | /api/reset     | Сбросить весь прогресс           |
  +--------+----------------+----------------------------------+

  Тело запроса /api/answer:
       { "questionIndex": 0, "chosenIndex": 2 }

  Формат ответа:
       {
         "currentIndex": 1,
         "score": 1,
         "answered": [0]
       }

  Поля:
       currentIndex — индекс текущего вопроса
       score        — количество правильных ответов
       answered     — список индексов отвеченных вопросов

----------------------------------------------------------------
  КАК ЭТО РАБОТАЕТ
----------------------------------------------------------------

  1. При загрузке "/" Flask читает состояние из session
     и передаёт его в шаблон через window.INITIAL_STATE.

  2. Клиент отправляет POST /api/answer — сервер проверяет
     ответ, обновляет score и добавляет индекс в answered.

  3. POST /api/next увеличивает currentIndex.

  4. Когда currentIndex >= количества вопросов, показывается
     экран с итоговым счётом.

  5. POST /api/reset очищает session, страница перезагружается.

  ВАЖНО: вопросы дублируются — на сервере (только правильные
  ответы) и на клиенте (тексты + варианты). Это сделано
  в учебных целях. В реальном проекте вопросы лучше отдавать
  через API.

----------------------------------------------------------------
  БЕЗОПАСНОСТЬ
----------------------------------------------------------------

  В app.py захардкожен секретный ключ — это нормально только
  для разработки. Для продакшена используй переменную окружения:

       import os
       app.secret_key = os.environ.get('SECRET_KEY',
                                      'dev-secret-change-me')

  Запуск:

       export SECRET_KEY="your-super-secret-key"   # Linux/macOS
       set SECRET_KEY=your-super-secret-key        # Windows
       python app.py

  Также отключи debug=True перед деплоем!
